# 🚀 BasicBasics: Getting Started with R
This repository is my workspace for going through the [RLadies](https://rladiessydney.org/courses/summary) Sydney BasicBasics tutorial. I am using this project to make sure my foundation in R and RStudio is rock solid before diving into more complex data analysis and multi-omic pipelines.

# 🔬 What I'm working on in this repo
For this tutorial, it's all about the fundamentals of setting up a clean, reproducible workflow. A few specific things I am working on here:

- Navigating the RStudio environment (understanding the difference between the Console, Environment, and Scripts).
- Setting up R Projects to keep my data, scripts, and outputs organized in one place (no more messy file paths!).
- Understanding the mechanics of installing, loading, and managing R packages.
- Writing clean, reproducible scripts that I can easily look back on later.
- Manipulating and creating new variables in my data
- Different methods of visualization (plots, histograms, boxes, etc)

# 💻 Tools used
Languages & IDE: R (in RStudio)
